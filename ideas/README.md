# Ideas e investigación

Una idea = un fichero `kebab-case.md` creado a partir de [`_plantilla.md`](_plantilla.md).

**Desde el iPhone:** crea un issue con la plantilla *Idea* en la app de GitHub y luego pide a
Claude Code: *"Investiga el issue #N y crea la nota en `ideas/` con la plantilla"*.

Estados: 💡 idea · 🔍 investigando · 🛠️ prototipo · ✅ lanzada · 🗄️ archivada
